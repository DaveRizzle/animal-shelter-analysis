# animal-shelter-analysis
# Capstone SQL Project

This project analyzes the total annual cost to run animal shelters, focusing on costs by animal type and size (e.g., small dogs, large cats). It calculates costs based on animal size/type, age, and shelter location, excluding sponsored animals. The analysis uses SQL to process data from multiple tables, categorizing animals by updated size criteria and incorporating additional costs for age and location. The output includes a table with total costs per animal type/size combination and a percentage of the total cost for visualization purposes. The project is built using PostgreSQL and includes a sample query to demonstrate the cost calculation logic.
